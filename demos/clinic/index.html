ได้รับคำขอแล้ว (ตัวอย่าง) — ในเว็บจริง ข้อมูลจะถูกบันทึกลง Google Sheets ของคลินิก และแจ้งเตือนเจ้าหน้าที่ทาง LINE OA

ในเว็บจริง: แบบฟอร์มเชื่อม Google Apps Script → บันทึกลง Sheet → แจ้งเตือนผ่าน LINE Messaging API พร้อมข้อความยินยอมตาม PDPA
